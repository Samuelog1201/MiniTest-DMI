# ¿Qué perfil DMI vibra más contigo?

Aplicación web interactiva desarrollada con React, Vite y TailwindCSS para estudiantes interesados en descubrir qué perfil de Diseño de Medios Interactivos se relaciona más con sus intereses y habilidades.

El test analiza respuestas relacionadas con:
- UX Design
- UI Design
- Desarrollo de Interfaces

Además, al finalizar, recomienda una posible ruta vocacional dentro del ecosistema DMI.

---

# Características principales

- Experiencia interactiva y responsive
- Diseño mobile first
- Resultados dinámicos personalizados
- Sistema de porcentajes UX / UI / DEV
- Resultados visuales con imágenes
- Rutas vocacionales personalizadas
- Animaciones modernas con Framer Motion
- Integración con Supabase para analytics
- Diseño basado en identidad visual de Icesi
- Deploy preparado para Vercel

---

# Tecnologías utilizadas

Frontend:
- React
- Vite
- TailwindCSS
- Framer Motion

Backend / Analytics:
- Supabase

Deploy:
- Vercel
