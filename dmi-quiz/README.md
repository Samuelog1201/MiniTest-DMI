# 🎯 ¿Qué perfil DMI vibra más contigo?

Un quiz interactivo moderno para descubrir si tu perfil es más **UX**, **UI** o **DEV**.

## 🚀 Inicio Rápido

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) y comienza el test.

## ✨ Características

- ⚡ Experiencia ultrarrápida y fluida
- 📱 100% responsive y mobile-first
- 🎨 Diseño minimalista tipo Stripe/Linear
- 🎭 Animaciones suaves con Framer Motion
- 🌈 Colores y tipografía oficial Icesi
- 🔄 Transiciones elegantes entre pantallas

## 🎯 Cómo Funciona

1. Responde 8 preguntas sobre tu perfil
2. El sistema calcula automáticamente tu puntuación
3. Descubre si eres UX, UI o DEV
4. Ve tu perfil personalizado con fortalezas

## 🛠️ Tech Stack

- React 19 + Vite 5
- TailwindCSS 3
- Framer Motion
- JavaScript vanilla

## 📊 Resultados

### 👥 Eres UX
Piensas en las personas primero. Empatía, investigación, resolución de problemas.

### 🎨 Eres UI  
Tu mente conecta con lo visual. Creatividad, estética, comunicación visual.

### ⚙️ Eres DEV
Te emociona construir cosas. Lógica, arquitectura, performance.
